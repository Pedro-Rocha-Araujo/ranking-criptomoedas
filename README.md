# Ranking de Criptomoedas 💵
## O presente repositório foi criado com intuito de hospedar um projeto front-end de listagem de criptomoedas
<img width="1920" height="911" alt="thumbnail" src="https://github.com/user-attachments/assets/6cd4d29b-d5f8-4a10-a9c9-b45b45642852" />

### Funcionalidades ⚙️
* Listagem ordenada das criptomoedas mais valiosas
* Pesquisa com filtro por nome
* Conta com um card de detalhes, especificando sobre a criptomoeda desejada
### Características 🗹
* Desenvolvido em Next.js
* Consumo de API 
* Abordagem Mobile-first (100% Responsivo)
